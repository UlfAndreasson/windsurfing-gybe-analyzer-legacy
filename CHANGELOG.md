# Changelog

## 0.3.1 — 2026-10-14

- Changed default local port from `8765` to `8776` to avoid collision with Portfolio Local.
- Added `GYBE_PORT` environment variable override for `run.sh` and `run-dev.sh`.

## 0.3.0 — 2026-10-13

- Initial working local application.
- FIT/ZIP import.
- GPS track extraction and turn detection.
- Per-turn speed, retention, duration, course, turn-rate and effective-radius metrics.
- Session track, turn table, arc plot and second-by-second speed detail.
