# Brand assets

Reusable Windsurfing Gybe Analyzer artwork:

- `windsurfing-gybe-analyzer.png` — 512×512 black/white PNG for app icons, browser icons and other raster use.
- `windsurfing-gybe-analyzer.svg` — scalable vector version used in the main README and suitable for docs/branding.

Keep these filenames stable so future app, favicon and documentation work can reuse the same artwork.
